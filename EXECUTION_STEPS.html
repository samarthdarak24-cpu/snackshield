🛡️ SnackShield - Project Execution Steps

Project: Blockchain-Based Fake Product Detection System
Tech Stack: MERN (MongoDB, Express, React, Node.js) + Ethereum Smart Contracts
Repository: https://github.com/samarthdarak24-cpu/snackshield
Submission Date: 16th May 2026

📋 Prerequisites

  • Node.js (v16+), MongoDB (v5.0+), Git, Hardhat

🚀 Quick Start Guide

1. Clone Repository

git clone https://github.com/samarthdarak24-cpu/snackshield.git
cd snackshield

2. Install Dependencies

# Server
cd snackshield-mern/server && npm install

# Client
cd ../client && npm install

# Blockchain
cd ../blockchain && npm install

3. Environment Setup

Server (.env in snackshield-mern/server/): 
MONGODB_URI=mongodb://localhost:27017/snackshield
JWT_SECRET=your_jwt_secret_key
PORT=5000
BLOCKCHAIN_RPC_URL=http://127.0.0.1:8545

4. Start Services

# Terminal 1: Start MongoDB
mongod

# Terminal 2: Deploy Smart Contracts
cd snackshield-mern/blockchain
npx hardhat node
# In new terminal: npx hardhat run scripts/deploy.js --network localhost

# Terminal 3: Start Server
cd snackshield-mern/server && npm run dev

# Terminal 4: Start Client
cd snackshield-mern/client && npm run dev

5. Access Application

  • Frontend: http://localhost:5173
  • Backend API: http://localhost:5000
  • Blockchain: http://localhost:8545
